# Acerca de Casa Holhins Web System

Bienvenido a la Wiki oficial del proyecto Casa Holhins CRM.

## Propósito
Este sistema nace como Evidencia Integradora de las Fases III y IV del Certificado en Java Avanzado de Tecmilenio. 
El objetivo es proveer a la empresa **Casa Holhins** (ubicada en Tizayuca, Hidalgo) de una herramienta digital ligera y eficiente para centralizar su cartera de clientes y administrar el catálogo de servicios holísticos que ofrecen.

## Tecnologías Principales
- **Backend:** Java 11
- **Contenedor Web:** Apache Tomcat 10.1+
- **Especificación:** Jakarta EE 10 (Servlets 6.0, JSP)
- **Base de Datos:** H2 Database (modo embebido)
- **Frontend:** Bootstrap 5 (vía CDN), JSP Taglibs (JSTL 3.0)
- **Seguridad:** BCrypt (librería `at.favre.lib`) para contraseñas de usuarios.
- **Testing:** JUnit 5
- **CI/CD:** GitHub Actions
